# BIOCWT — Wood Product Services Website

A responsive, minimalist static website for a wood product and services brand. The project is built with plain HTML, CSS, and JavaScript and includes a landing page, service pricing, gallery, contact page, about page, and custom 404 page.

## Pages

- `index.html` — home page
- `pages/about-us.html` — about page
- `pages/gallery.html` — gallery page
- `pages/prices-for-services.html` — services and pricing page
- `pages/contact.html` — contact page
- `pages/404.html` — custom not-found page

## Project structure

```text
.
├── index.html
├── style.css
├── script.js
├── pages/
├── resources/
└── font/
```

## Running locally

No build tools or dependencies are required. Open `index.html` in a browser, or serve the project with any local static server.

For example, with VS Code, open the project using Live Server and visit the local URL it provides.

## Design and implementation notes

The website was implemented from a Figma template created by [Daria Korkishko](https://www.figma.com/@glosdashka).

The implementation may differ slightly from the original Figma design in the following ways:

- Hover effects were added to buttons and navbar links.
- A footer was added to the 404 page even though it was not included in the original Figma design.
- Small gaps, spacing, and padding values may vary slightly.
- The wooden pattern graphic may appear behind assets rather than above them, depending on the section and responsive layout.
- Some image, typography, button, and component dimensions may differ slightly.
- Responsive behavior was adapted for browser widths and practical HTML/CSS implementation.
